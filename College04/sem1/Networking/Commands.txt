
Command modes: {Use '?' to see all the command in each mode of the terminal} {use command exit/end to return to the previous command mode}
  1. User Exec mode: 
      eg: Router > 
      The '>' symbolizes that we are in this mode. 

  2. Privilege exec mode {use command enable to get into this mode from mode 1}
      eg. Router #

  3. Global configuration mode {use command configure terminal to enter this mode from mode 2}
      eg. Prompt(config)#
      can also be Router(Config)#


  User Exec mode

  |                     ^
  |enable               | exit 
  *                     |

  Privilege Exec mode

  |                     ^
  |configure terminal   | exit 
  *                     |

  Global configuration mode


  In Global configuration mode
  #hostname
    use this command in global configuration mode to change/set the desired hostname
    usage: hostname name

  #enable
    use this command with 
    
    >> password 
      to change/set the desired password
      usage: enable password ****

    >> secret(To encrypt the password)
      to change/set the desired password in encrypted format
      usage: enable secret ciscoSecret

  # no ip domain-lookup
    use this command to make sure that the packettracer doesn't start looking up typos as codes.

  # service password-encryption
    Use this command to encrypt the plaintext password

  # line console 0
    to get into line console and the '0' means that there is only one person configuring at the moment
    we get into (config-line) when this command is executed 
    
    >> password **** 
        to set password in this mode

    >> login 
        to login into the config-line mode
    
    >> logging synchronous 
        to make sure that no reply is seen in the terminal when commands are executed.

    >> exec-timeout 10
      use this to make it so that it disconnects after 10 mins.

  # line vty 0 4 {the 0,4 makes sure that 5 users i.e 0 to 4 are able to config at once}
    vty means virtual terminal
    to get into vty mode 

    >> password **** 
        to set password 

    >> login 
        to make sure that we can login later on.

  # banner motd */# Authorized only! */#
    use either * or # not both
  
  #security password min-length 10  
    use this to set the minimum password length to 10

  #interface Fa0/0 
    use this to select the port or interface

  #ip address 192.168.1.1 255.255.255.0
    use this to set the ip address and the subnet mask 

  #no shutdown
    use this to make sure that the device is on and data is transmitted.


  In Privilege Exec mode

  #show running-config
    use this code to view all the past commands and the current configuration.

  #clock set hh:mm:ss mm dd yy
    use this to set time and date 

  #show clock 
    use this to see the clock

Bit: Either 0 or 1

Ip address is a logical address.
  which is designated to specific location of a device on a network.

Ipv4 address = 32 bit

Within each network there are three types of IP addresses:
  >> Network address
  >> Host address
  >> Broadcast address


Methods of communications:
  Unicast: One to one communication 
  Broadcast: One to all communication in a network segment
  Multicast: One to many communication

Private ip address ranges
+---------------------------+--------------------------------+
| Network Address and prefix|RFC 1918 Private address range  |
--------------------------------------------------------------
10.0.0.0/8                      10.0.0.0 - 10.255.255.255
172.16.0.0/12                   172.16.0.0 - 172.31.255.255
192.168.0.0/16                  192.168.0.0 - 192.168.255.255

Reasons for segmentation of networks:
  >>Reduces overall network traffic and improve Efficiency
  >>Can be used to implement security policies
  >>Helps reduce number of devices if something goes wrong 
  >>They are also used for segmenting various locations, groups and devices
