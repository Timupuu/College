Command modes: {Use '?' to see all the command in each mode of the terminal} {use command exit/end to return to the previous command mode}
  1. User Exec mode: 
      eg: Router > 
      The '>' symbolizes that we are in this mode. 

  2. Privilege exec mode {use command enable to get into this mode from mode 1}
      eg. Router #

  3. Global configuration mode {use command configure terminal to enter this mode from mode 2}
      eg. Prompt(config)#
      can also be Router(Config)#


  User Exec mode

  |                     ^
  |enable               | exit 
  *                     |

  Privilege Exec mode

  |                     ^
  |configure terminal   | exit 
  *                     |

  Global configuration mode

  #hostname
    use this command in global configuration mode to change/set the desired hostname
    usage: hostname name

  #enable
    use this command with 
    
    >> password

      usage: enable password ****

    >> secret(To encrypt the password)
      to change/set the desired password in encrypted format
      usage: enable secret ciscoSecret

  # no ip domain-lookup

  # service password-encryption
    Use this command to encrypt the plaintext password

    we get into (config-line) when this command is executed 
    
    >> password **** 
        to set password in this mode

    >> logging synchronous

Bit: Either 0 or 1

Ip address is a logical address.
  which is designated to specific location of a device on a network.

Ipv4 address = 32 bit

Within each network there are three types of IP addresses:
  >> Network address
  >> Host address
  >> Broadcast address


Methods of communications:
  Unicast: One to one communication 
  Broadcast: One to all communication in a network segment
  Multicast: One to many communication

Private ip address ranges
+---------------------------+--------------------------------+
| Network Address and prefix|RFC 1918 Private address range  |
--------------------------------------------------------------

192.168.0.0/16                  192.168.0.0 - 192.168.255.255

Reasons for segmentation of networks:
  >>Reduces overall network traffic and improve Efficiency
  >>Can be used to implement security policies
  >>Helps reduce number of devices if something goes wrong 
  >>They are also used for segmenting various locations, groups and devices
