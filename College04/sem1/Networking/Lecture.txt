Domain name service

Domain names were created to convert the numeric IP address into a simple, recognizable name.

Fully qualified domain name (FQDns) such as https://www.cisco.com are much easier for people to remember than 198.133.219.25.

The DNS protocol defines an automated service that matches resources names with the required numeric network address. IT includes the format for queries responses and data.

The DNS server stores different types of resource records that are used to reoslve names. These records contain the name, address, and the type of record.

Some of these record types are as follows:
>> A -- An end device IPv4 address
>> N -- An authoritative name server
>> AAAA -- An end device IPv6 address(pronounced Quad-A)
>>MX -- A main exchange record 

DNS is like a phonebook. It contains the number of various places and institutions. If it doesn't contain what we want it will contact other and give us the contact.
