The syntax for one dimensional array is 
datatype[] array_name;

The syntax for constructing one dimensional array is:
array_name = new datatype[x];

The syntax in one line will be:
datatype[] array_name = new datatype[x];


The syntax for two dimensional array is 
datatype[][] array_name;

The syntax for constructing two dimensional array is:
array_name = new datatype[x][y];

The syntax in two line will be:
datatype[][] array_name = new datatype[x][y];
